## Project Description
-This is a sveltkit project that uses tailwind and some flowbite UI components.

## Project Objective
-The project allow users to upload an image or pick one of the images of the gallery and then visualize the image in a simulated painting frame where borders (frame) are made with a html div element. 
-The user can then customize the frame dimensions, add or remove the frame, add or remove a pass-partout. 
-Finally, the user can transform this configuration into a model-viewer scene where they can validate and also trigger an augmented reality experience AR.
